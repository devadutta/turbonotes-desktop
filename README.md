# TurboNotes for the desktop

Downloads of the TurboNotes desktop app for macOS: Markdown notes in a folder on your computer, synced with Git.

Get the `.dmg` from the [latest release](https://github.com/devadutta/turbonotes-desktop/releases/latest), open it, and drag TurboNotes to Applications. It runs on Apple silicon and Intel, it's signed and notarized by Apple, and it updates itself from the releases here.

This repository holds only the releases.
